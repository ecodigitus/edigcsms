03

Urutan interaksi

Alur antar-pihak dari pengisian sampai status lulus tercatat.

sequenceDiagram
  actor V as Vendor
  participant ED as Edigcsms
  participant PK as Portal KKKS
  participant TP as Tim Penilai KKKS
  participant EC as e-CHSEMS
  V->>ED: Isi kuesioner 8 elemen + unggah bukti
  ED-->>V: Skor prediksi + daftar gap
  V->>ED: Perbaiki gap sampai siap
  ED-->>V: Paket PK siap-submit
  V->>PK: Upload paket (manual)
  PK->>TP: Teruskan untuk penilaian
  TP->>TP: Verifikasi dokumen + lapangan + skoring
  TP->>EC: Input Nilai Kualifikasi K3LL
  EC-->>V: Status "lulus CSMS" (lintas KKKS)
04

Batas peran Edigcsms

Yang dikerjakan

  • Wizard 8 elemen + template & checklist bukti
  • Simulasi skor (≥60% / ≥54,3%) & gap analysis
  • Repository dokumen reusable lintas tender
  • Paket "siap-submit" untuk di-upload ke portal KKKS

Di luar cakupan

  • Tidak terhubung otomatis ke CIVD / e-CHSEMS / portal KKKS
  • Tidak menerbitkan sertifikat — penilai tetap tim KKKS
  • Tidak menggantikan verifikasi lapangan
  • Output = kesiapan, bukan jaminan lulus
